TeraPhotoStudio V3 - Background Fix + Cutting Border

Passport workflow:
- Auto crop to selected aspect ratio
- Background replacement
- 8/16/32 copies
- A4 photo-only sheet
- PDF and print
- Optional cutting border around every photo (Black Thin default)

The cutting border is drawn inside each photo edge so it is visible on paper and helps with trimming without changing the intended photo dimensions.
